# AI 預測維護方案

## 方案概述

透過 IoT 感測器收集設備運轉數據，結合機器學習模型預測設備故障，從被動維修轉為主動預防。

## 適用場景

- 設備故障造成產線停機損失大
- 維修成本高、備品庫存管理困難
- 已有部分感測器但數據未被利用

## 方案架構

```
感測器 → 數據採集 → 特徵工程 → ML 模型 → 預警系統 → 維修排程
```

## 交付項目

| 階段 | 交付物 | 期間 |
|------|--------|------|
| 診斷 | 設備盤點、數據可用性評估 | 2-4 週 |
| PoC | 單一設備類型的預測模型 | 4-6 週 |
| 擴展 | 全廠部署、Dashboard | 8-12 週 |
| 移轉 | 教育訓練、維運手冊 | 2-4 週 |

## 預期效益

- 非計畫停機減少 30-50%
- 維修成本降低 20-30%
- 備品庫存優化 15-25%

## 成功要素

- 設備已有基礎感測器或可加裝
- 至少 6 個月歷史數據
- 內部有 IT 人員可接手維運
