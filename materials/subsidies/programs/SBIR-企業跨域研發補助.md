# SBIR 企業跨域研發補助

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部中小及新創企業署 |
| 大類 | 跨域研發 |
| 補助額度 | 最高新臺幣 700 萬元（補助比例≦50%） |
| 申請資格 | 至少2家企業組成研發聯盟（含至少1家新創） |
| 申請期間 | 115年度第一梯次已結束，下一梯次待公告 |
| 申請連結 | https://sbir.org.tw/cross/info |

## 補助範圍

有別於一般 SBIR 個別申請，本計畫鼓勵「一間成熟中小企業 + 一間有技術的新創」組成跨域研發聯盟，聯合申請最高 700 萬元補助。

三大計畫主軸：
- **AI 智慧應用**：製程智慧化、供應鏈決策、異常診斷等
- **無人載具應用**：自主控制、任務協作、感測融合於製造、物流、農漁等場域
- **淨零應用**：節能減碳、循環經濟、能源優化、碳盤查等

115年度新增：專利申請費補助（國內上限3萬元、國外上限10萬元）。

## 適用場景

- 有技術需求的傳統製造業，搭配 AI / IoT 新創聯合申請
- 需導入無人機、AGV 等載具的物流或農漁企業
- 有淨零轉型需求的中小企業，結合碳管理新創
