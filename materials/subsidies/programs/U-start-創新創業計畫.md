# U-start 創新創業計畫

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 教育部青年發展署 |
| 大類 | 青年創業 |
| 補助額度 | 第1階段：每隊補助 50 萬元創業基本開辦費（含學校育成費用 15 萬元）。
第2階段：績優團隊可獲 35 萬～100 萬元創業獎助。 |
| 申請資格 | （一） 第1階段由青年團隊提出創業計畫及學校育成單位提出輔導計畫共同申請，經評選通過者，可獲補助50萬元之創業基本開辦費（其中15萬元為學校育成費用）。
（二） 第2階段創業績優團隊，由通過第1階段補助且完成主管機關設立登記之創業團隊提出申請，獲選團隊可獲得 35萬至100萬元之創業獎助。
（三） 前述青年團隊3人以上組隊申請，其中應有 2/3 以上成員為近 5 學年度畢業生或大專校院在校生。其餘團隊成員可為社會人士或取得居留簽證之外籍人士，社會人士及外籍人士須為 18 歲 （ 含 ） 以上至 35 歲 （ 含 ） 以下青年。 |
| 截止日期 | 第1階段：每年1–2月｜第2階段：每年8–9月 |

## 補助範圍

「U-start創新創業計畫」係結合學校育成輔導資源，提供青年創業實驗場域與第一桶金，並設有創業門診、實地訪視服務、創業社群連結及成果展現，提升青年創業知能及實戰能力，進而帶動校園創新創業氛圍。

## 申請資格詳情

（一） 第1階段由青年團隊提出創業計畫及學校育成單位提出輔導計畫共同申請，經評選通過者，可獲補助50萬元之創業基本開辦費（其中15萬元為學校育成費用）。
（二） 第2階段創業績優團隊，由通過第1階段補助且完成主管機關設立登記之創業團隊提出申請，獲選團隊可獲得 35萬至100萬元之創業獎助。
（三） 前述青年團隊3人以上組隊申請，其中應有 2/3 以上成員為近 5 學年度畢業生或大專校院在校生。其餘團隊成員可為社會人士或取得居留簽證之外籍人士，社會人士及外籍人士須為 18 歲 （ 含 ） 以上至 35 歲 （ 含 ） 以下青年。
