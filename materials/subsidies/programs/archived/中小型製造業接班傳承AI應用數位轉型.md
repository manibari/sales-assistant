## 補助標的

鼓勵具有接班規劃之中小型製造業者展開接班傳承，由接班人利用數位科技與AI加速數位轉型，透通產銷，健全供應鏈管理與客戶關係管理之數位化能力，朝新市場開發或新通路拓展進行商業模式轉型。

計畫須包含：
1. **創新商業模式**：企業以新市場開發（創造新的客群）或新通路拓展（創造新的服務傳遞管道）為主題，至少須包含關鍵客戶、價值主張、市場機會、競爭優勢、執行方式等
2. **數位科技與AI**：以供應鏈管理、客戶關係管理進行優化為重心；提案內容必須納入至少一項AI技術導入並串接於新商模

## 申請資格

### 中小型製造業者
- 依法辦理公司登記或商業登記（不含國營事業分公司及外國營利事業在臺設立之分公司）
- 須依法辦理工廠登記
- 合併年營業收入 ≤ 20億元（中堅企業放寬至100億元）
- 公司淨值應為正值
- 非屬銀行拒絕往來戶

### 計畫主持人
- 為企業規劃之接班人選（3年內完成或預計接班）
- 須為負責人、董監事或持股超過10%大股東的本人或三等親屬
- 或加入公司滿10年且為一級主管
- 或為集團「人才發展委員會」接班人名單之一

## 提案重點

| 項目 | 內容 |
|------|------|
| 現況分析與轉型目標設定 | 公司簡介、市場競爭分析、轉型動機與目標 |
| 概念驗證(POC)成果 | 已完成之小範圍導入成果，含驗證指標 |
| 轉型策略與藍圖 | 中長期轉型藍圖，分年發展策略（須經董事會通過） |
| 轉型實踐作法 | 創新商業模式 + 數位科技AI + 資安規劃 + 商業驗證POB規劃 |
| 團隊組成 | 接班傳承規劃、計畫團隊、委外業者清單 |
| 可行性分析與成效 | 數位準備度、預估效益、風險評估、經費合理性 |

## 審查流程

```
提出申請 → 資格審 → 技術審（書面+會議） → 決審 → 簽約 → 執行
```

## 注意事項

- 僅適用「申請個案標的」，已開發或導入完成之系統不得申請
- 不得委託代辦或顧問公司代寫計畫書
- 不得與類似計畫重複申請
- 結案前須完成服務及商業驗證
- 必要效益須占計畫權重20%以上

## 適用場景

- 製造業接班傳承中的企業
- 想透過 AI 加速數位轉型的中小型製造業
- 需要供應鏈管理、CRM 數位化的傳統製造業
