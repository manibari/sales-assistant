# 115年度中小微企業AI創新應用輔導計畫

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部中小及新創企業署 |
| 大類 | AI創新／國際市場拓展 |
| 補助額度 | 甄選 8 家輔導廠商 |
| 申請資格 | 中小企業（資本額 < 1 億或員工 < 200 人）、TRL 6+ |
| 截止日期 | 115年4月30日 17:00 (2026-04-30) |
| 申請連結 | https://www.sme.gov.tw/article-tw-2275-14442 |

## 補助範圍

針對半導體周邊供應鏈相關產業，協助業者切入捷克、波蘭等中東歐市場，重點領域：

- 半導體設備、材料、工程
- 智慧製造、AI 自動化設備
- 智慧物流管理應用

採兩階段書面審查與現場簡報甄選，最終選出 8 家進行海外輔導。

## 適用場景

- 半導體設備、材料、工程業者欲開拓捷克／波蘭市場
- AI 自動化、智慧製造業者尋求歐洲半導體聚落合作
- 已具 TRL 6+ 技術成熟度，準備國際化的中小企業
