# 中小型製造業低碳及智慧化升級轉型個案補助

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部產業發展署 |
| 大類 | 低碳智慧化 |
| 補助額度 | 每案上限 300 萬元（自籌款≧50%） |
| 申請資格 | 中小型製造業（依法辦理工廠登記） |
| 申請期間 | 9人以下已停止受理；10人以上115年度待公告 |
| 申請連結 | https://www.uat.org.tw/ |

## 補助範圍

針對中小型製造業提供低碳化及智慧化升級轉型個案補助：

- **低碳化**：製程節能改善、碳排放減量、循環經濟導入、綠色製程開發
- **智慧化**：智慧製造系統、自動化設備導入、數位管理系統建置、IoT 感測應用

申請方式一律採線上申請（https://www.uat.org.tw），紙本不受理。

## 適用場景

- 有工廠登記的中小型製造業，想導入節能減碳設備
- 需要升級自動化產線或導入智慧製造系統的工廠
- 面臨碳盤查/碳關稅壓力需要轉型的出口型製造業
