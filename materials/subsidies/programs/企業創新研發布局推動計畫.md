# 企業創新研發布局推動計畫

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部產業技術司 |
| 大類 | 研發補助 |
| 補助額度 | 每案最高新臺幣 3,000 萬元 |
| 申請資格 | 依法登記之國內企業（中小企業至大型企業皆可） |
| 截止日期 | 公告日起 7 日後受理，至 115年12月31日（2026-12-31）截止 |

## 補助範圍

協助企業強化研發能量、規劃中長期技術藍圖，補助項目涵蓋：

- 研發人事費、設備、耗材
- 專利申請費
- 委託研究與人才培訓
- 研發體系優化與中長期技術藍圖規劃之顧問輔導

## 適用場景

- 有意建立內部研發體系、布局中長期技術藍圖的成長型企業
- 需要較大額度（最高 3,000 萬元）支持單一研發專案的中堅企業
- 製造業／科技業欲透過研發布局提升競爭力者
