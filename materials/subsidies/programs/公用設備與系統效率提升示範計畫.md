# 公用設備與系統效率提升示範計畫

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部能源署 |
| 執行單位 | 財團法人工業技術研究院 |
| 大類 | 淨零轉型（補助型） |
| 補助額度 | 每 kW 新臺幣 700~4,500 元 |
| 申請資格 | 法人、公法人及醫療機構等能源用戶 |
| 截止日期 | 官網未載明（常態受理） |
| 諮詢窗口 | 工研院 楊竣翔經理／03-591-9258 |
| 計畫網站 | https://www.mdss.org.tw/subsidy/index/index.aspx |

## 補助範圍

補助購置高效率公用／動力設備，加速汰換老舊機組：

- 高效率空壓機
- 風機
- 泵浦
- IE4 高效率電動機

補助金額依設備額定功率（kW）計算，每 kW 700~4,500 元。

## 適用場景

- 廠務端（空壓、冷凍、泵浦系統）汰換專案的硬體補助來源，與 IoT/SCADA 能源監控導入天然搭配
- 醫療機構同樣適用，是少數把醫院納入的能源補助
- 提案時可用「補助抵掉部分硬體 → 監控與分析由我們做」的組合拳降低客戶總價感受

## 注意事項

- 與「補助中小用戶導入節能服務」同為能源署工研院窗口（楊竣翔經理），兩案定位不同但需確認不重複請領
