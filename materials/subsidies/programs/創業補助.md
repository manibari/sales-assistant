# 創業補助

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 台北市政府產業發展局 |
| 大類 | 創業補助 |
| 補助額度 | 每案補助新臺幣100萬元，以總經費50%為上限 |
| 申請資格 | 新設立1年內之臺北市公司或商業 |
| 截止日期 | 隨到隨審（全年受理） |

## 補助範圍

申請人所提「創業計畫」應以技術、服務、產品或內容創新為核心，並具發展潛力之營運模式，且計畫內容須具備市場營運目標，並可反映市場價值及潛藏商機。

## 申請資格詳情

新設立1年內之臺北市公司或商業
