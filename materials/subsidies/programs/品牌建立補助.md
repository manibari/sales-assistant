# 品牌建立補助

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 台北市政府產業發展局 |
| 大類 | 品牌建立補助 |
| 補助額度 | 最高補助計畫總經費 50% ，補助款 500萬元 |
| 申請資格 | 設立登記滿1年以上之臺北市公司、商業或所在地登記於本市之外國公司 |
| 截止日期 | 隨到隨審（全年受理） |

## 補助範圍

申請人所提「品牌建立計畫」係指建立新創品牌、既有品牌升級或再造，具有開發新客群、新市場或建立新通路，並有助提升品牌價值與能見度及國際市場競爭優勢，計畫期間須達成經營面效益，包含建立國際通路、擬定進入國際市場策略等。

## 申請資格詳情

設立登記滿1年以上之臺北市公司、商業或所在地登記於本市之外國公司
