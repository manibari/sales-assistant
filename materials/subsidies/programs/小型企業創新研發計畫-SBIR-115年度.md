# 小型企業創新研發計畫 (SBIR) — 115年度

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部中小及新創企業署 / 執行：財團法人中衛發展中心 |
| 大類 | 小型企業創新研發 |
| 補助額度 | Phase 1（先期研究）：每案最高150萬元，期程6個月。
Phase 2（研究開發）個別申請：每年最高600萬元，全程最高1,200萬元，期程6個月～2年。
Phase 2 聯盟申請：每年最高(成員家數×500萬)，全程最高(成員家數×1,000萬)，上限3,000萬，期程9個月～2年。
Phase 2+（加值應用）個別：每年最高600萬元，全程最高1,200萬元。
Phase 2+ 聯盟：全程最高(成員家數×500萬)，上限2,500萬元。
補助款不超過計畫總經費50%；自籌款≦實收資本額。 |
| 申請資格 | 符合「中小企業認定標準」：實收資本額≦1億元，或經常僱用員工數未滿200人。
不得有：5年內政府計畫重大違約/停權、3年內欠稅、已享有其他補助租稅優惠、
  近3年環保/勞工/食安重大違規、近3年金融犯罪判決確定、陸資投資、
  本國或外國分公司、公司狀態為解散/撤銷/停業/歇業。
執行場所須在我國管轄區域內。
聯盟申請：主導企業須為中小企業，成員中中小企業占比≧60%，成員間不得為關係人。 |
| 截止日期 | 隨到隨審（全年受理） |

## 補助範圍

研發領域：資通、電子、機械、生技製藥、民生化工、服務（六項領域）。
申請階段：先期研究(Phase 1)→研究開發(Phase 2)→加值應用(Phase 2+)。
申請類型：個別申請（1家）/ 聯盟申請（3家以上，中小企業≧60%）。
可導入轉委託、技術引進或顧問諮詢，技術移轉及委託費以不超過總經費60%為原則。

## 115年度新增

- **專利申請費補助**：國內專利補助上限 3 萬元，國外專利補助上限 10 萬元（適用於 SBIR 計畫通過之企業）

## 申請資格詳情

符合「中小企業認定標準」：實收資本額≦1億元，或經常僱用員工數未滿200人。
不得有：5年內政府計畫重大違約/停權、3年內欠稅、已享有其他補助租稅優惠、
  近3年環保/勞工/食安重大違規、近3年金融犯罪判決確定、陸資投資、
  本國或外國分公司、公司狀態為解散/撤銷/停業/歇業。
執行場所須在我國管轄區域內。
聯盟申請：主導企業須為中小企業，成員中中小企業占比≧60%，成員間不得為關係人。
