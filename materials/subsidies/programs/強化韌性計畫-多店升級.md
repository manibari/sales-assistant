# 強化韌性計畫 — 個案補助-多店升級（最高 300 萬元）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部商業發展署 |
| 執行單位 | TISSA |
| 補助上限 | 300 萬元 |
| 政府補助比例 | 50% |
| 聯絡電話 | (02) 2553-3988 #681 |
| Email | smebiz@tissa.org.tw |

## 補助對象

多家業者共同申請，導入AI升級擴散

## 計畫重點

- **營運優化**：營運流程自動化、人力與財務優化、庫存管理安全
- **服務優化**：智慧顧客經營管理、客戶體驗升級、銷售數據洞察

## 績效指標

- 帶動 20 至 50 家業者應用 AI 工具
- 教育訓練 1 場

## 申請期間

| 梯次 | 期間 |
|------|------|
| 第一梯 | 115/2/13 至 115/3/31 |
| 第二梯 | 115/8/3 至 115/8/31（暫定）|
| 第三梯 | 116/1/4 至 116/1/29（暫定）|

## 適用場景

- 多家店家聯合申請 AI 工具導入
- 連鎖體系想統一升級營運/服務數位能力
- 餐飲、零售、批發業聯合導入
