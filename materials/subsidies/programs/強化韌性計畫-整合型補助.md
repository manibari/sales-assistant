# 強化韌性計畫 — 整合型補助（最高 2,000 萬元）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部商業發展署 |
| 執行單位 | TISSA |
| 補助上限 | 2,000 萬元 |
| 政府補助比例 | 50% |
| 聯絡電話 | (02) 2553-3988 #681 |
| Email | smebiz@tissa.org.tw |

## 補助對象

跨域整合之商業服務業者，帶動供應鏈導入AI強化營運效率

## 計畫重點

- 智慧營運整合：強化服務營運效率、導入AI/IoT、智慧設備、數據分析
- AI能源管理：強化企業永續韌性、AI智慧能源管理、節能設備

## 績效指標

- 整合 3 處場域
- 帶動 200 家業者
- 營運效率提升 20%
- 能耗率提升 10% 或能績效佐證

## 申請期間

| 梯次 | 期間 |
|------|------|
| 第一梯 | 115/2/13 至 115/3/31 |
| 第二梯「AI能源管理」| 115/5/1 至 115/6/1（暫定）|
| 第三梯「智慧營運整合」| 115/9/1 至 115/9/30（暫定）|

## 適用場景

- 跨域整合的大型商業服務業者
- 想帶動供應鏈整體 AI 升級
- 有能力整合多個場域的企業
