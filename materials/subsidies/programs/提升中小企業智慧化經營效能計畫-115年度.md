# 提升中小企業智慧化經營效能計畫 — 115年度

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部中小及新創企業署 |
| 大類 | AI轉型輔導 |
| 補助額度 | 企業診斷服務免費；AI導入輔導依計畫規模核定 |
| 申請資格 | 依法登記之中小企業 |
| 申請期間 | 企業診斷至115/3/10截止；AI導入輔導持續受理 |
| 申請連結 | https://www.sme.gov.tw/article-tw-2275-14180 |

## 補助範圍

本計畫以「企業診斷服務」、「產業AI應用教案」及「AI導入應用輔導」三大措施，協助中小企業提升智慧化經營效能。

- **企業診斷服務**：由專業顧問為企業進行數位化、智慧化經營診斷，提出改善建議
- **產業AI應用教案**：與產業公協會合作，開發符合產業需求的AI應用教材與案例
- **AI導入應用輔導**：協助中小企業實際導入AI技術，從概念驗證到落地應用

服務窗口：中華民國資訊軟體服務商業同業公會 數位應用處一組，電話：(02)2553-3988

## 適用場景

- 想了解自身數位化程度及AI導入可行性的中小企業
- 有意導入AI但不知從何開始的傳統產業
- 公協會想為會員企業開發AI應用教材
