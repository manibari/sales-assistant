# 新創賦能中小企業升級轉型計畫 — 115年度

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部中小及新創企業署 / 執行：全國創新創業總會 |
| 大類 | 新創賦能 |
| 年度預算 | 2 億元 |
| 申請資格 | 設立未滿8年之新創企業（107年3月1日後成立） |

## 補助範圍

本計畫鼓勵「新創企業」與「中小企業」合作，以新創技術能量協助中小企業完成數位及淨零雙軸轉型：

- **數位轉型**：AI、IoT、雲端、大數據等技術導入
- **淨零轉型**：碳盤查、節能減碳、循環經濟解決方案
- **產業解決方案培育**：將新創技術打磨成可複製的產業解決方案

聯絡電話：(02)2332-8558（全國創新創業總會）

## 適用場景

- 有技術方案的新創公司，想找中小企業場域驗證
- 傳統中小企業想導入 AI / 數位工具但缺乏內部技術團隊
- 正傑科技／詠鋐智能可作為新創方，協助中小企業客戶申請
