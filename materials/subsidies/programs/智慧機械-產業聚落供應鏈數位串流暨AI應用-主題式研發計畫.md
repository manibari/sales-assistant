# 智慧機械-產業聚落供應鏈數位串流暨 AI 應用（主題式研發計畫）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部產業發展署 |
| 執行單位 | 財團法人中國生產力中心 |
| 補助上限 | **1,500 萬元**（全案總經費 50% 以內） |
| 申請截止 | **115年5月4日（2026-05-04）17:30** |
| 執行期限 | 至 116年10月31日 |
| 申請方式 | 線上收件：https://reurl.cc/W8xKyZ |
| 諮詢電話 | (02) 2755-5615 |

## 計畫目標

協助中小型製造業者結合上下游供應鏈業者，運用資訊系統串聯製造供應鏈，導入 AI 應用，帶動製造升級，發展智慧供應鏈及智慧製造模式。

## 申請資格

### 提案廠商（製造業）
- 合併營收 **≤ 30 億元**（中堅企業可放寬至 **100 億元**）
- 中華民國境內登記之獨資、合夥、有限合夥事業或公司
- 需辦理工廠登記
- 公司淨值為正值
- 非陸資投資企業

### 排除條件
- 本年度已申請「中小製造業接班傳承 AI 應用數位轉型」或曾獲「接班傳承數位轉型主題式研發計畫」且正在執行者
- 執行本計畫未結案或當年度已獲補助者
- 本次申請內容曾獲其他政府計畫補助者

## 補助項目

- 供應鏈資訊串聯（軟硬體、資通訊、資安整合）
- AI 加值應用（機器學習、深度學習、生成式 AI）
- 智慧機械元素（需包含 2 項以上）：大數據、精實管理、機聯網、CPS、數位化供需、機器人及自動化
- 資安防護（必含）
- **不含** ERP 系統建置
- 國內業者產品/服務佔 **35% 以上**

## 加碼補助

| 條件 | 加碼 |
|------|------|
| 中堅企業（卓越/潛力） | +10% |
| 新創事業（符合認定原則第二點） | +10% |

## 提案架構要求

1. 需提供先期規劃案結案報告或概念驗證報告（POC）
2. 須委由具備能量之 SI 業者協助建置（AU/IT/SI/DA/MA/AI 類）
3. 需包含資安業者（IS 類）
4. 計畫查核點須含：供應鏈串聯家數、OEE、Lead Time 效益
5. 需至少串聯 **4 家**供應鏈業者
6. 績效指標：OEE、Lead Time、ROI

## 適合客戶類型

- 有上下游供應鏈協作需求的中小製造業
- 正在推動智慧製造、生產數位化的廠商
- 有 AI 導入計畫但需政府補助資金的企業
