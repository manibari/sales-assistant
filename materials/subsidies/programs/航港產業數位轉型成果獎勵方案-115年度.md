# 115年度航港產業數位轉型成果獎勵方案

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 臺灣港務股份有限公司 |
| 截止日期 | 115年12月31日 (2026-12-31) |
| 獎勵上限 | 1,000 萬元（加碼最高 1,300 萬元） |
| 獎勵比例 | 專案費用 20-45% |
| 申請平台 | 行銷獎勵方案申請平臺 |
| 聯絡電話 | 886-7-5219000 |
| 地址 | 804004 高雄市蓬萊路10號 |

## 獎勵結構

### 基礎獎勵
- 專案費用的 20-45%
- 上限 1,000 萬元

### 加碼獎勵（資料介接）
- 申請人簽署資料共享承諾書
- 額外增加 5% 獎勵比例
- 上限再增加 300 萬元（合計最高 1,300 萬元）

## 申請資格

於臺灣國際/國內商港區內從事以下業務，且與臺灣港務公司有業務往來關係者：
- 貨物裝卸承攬
- 船舶貨運承攬
- 船務代理
- 貨櫃集散站經營
- 港埠相關業者

須提供租約、繳款通知或營運協議等業務往來證明。

## 補助範圍

數位化或智慧化管理、服務系統導入、港埠資料交換，包含：
- 數位化應用
- 智慧化管理
- AI 應用於港埠服務

## 應備文件

- 申請表
- 專案執行報告及實際投資費用表
- 切結書
- ICT 產品及廠商選用聲明
- 業務往來證明文件

## 適用場景

- 港埠物流業者想導入數位化管理系統
- 船務/貨運業者 AI 應用
- 港區資料交換平台建置
