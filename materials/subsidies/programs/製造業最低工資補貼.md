# 製造業最低工資補貼

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部產業發展署 |
| 大類 | 薪資補貼 |
| 補助額度 | 全職每人每月910元 / 部分工時每人每月480元，最多6個月 |
| 申請資格 | 營業額減少10%以上之製造業者 |
| 截止日期 | 115年6月30日（2026-06-30），經費用罄提前截止 |
| 申請連結 | https://assist.nat.gov.tw |

## 補助範圍

因應國際關稅衝擊，經濟部與勞動部共同推出製造業最低工資補貼：
- **全職員工**：每人每月補貼 910 元
- **部分工時員工**：每人每月補貼 480 元
- **補貼期間**：最多 6 個月
- **移工**：最低工資調升部分亦可納入補貼

申請方式採線上登記，需備申請書（含基本資料、投保證號）及存摺影本。

## 適用場景

- 受國際關稅衝擊、營業額下滑的製造業客戶
- 僱用大量基層員工的傳統製造業
- 有移工的工廠型企業
