# 雲市集工業館 — 雲端解決方案點數補助計畫（115年度）

## 基本資訊

| 項目 | 內容 |
|------|------|
| 主辦機關 | 經濟部產業發展署 / 執行：財團法人中國生產力中心 |
| 大類 | 數位轉型 |
| 補助額度 | 每家最高 5 萬數位點數（1 點 = NT$1），可折抵至多 1/2 服務費 |
| 申請資格 | 中小企業、製造業且工廠登記、非陸資 |
| 截止日期 | 115年9月29日 (2026-09-29)，額度用罄提前截止 |
| 申請連結 | https://www.sme.gov.tw/caas/article-caas-3059-17073 |

## 補助範圍

鼓勵製造業採購資訊服務業者提供之雲端解決方案（如雲端 ERP、雲端 POS、數位行銷工具等），以點數折抵服務費方式降低中小製造業導入數位工具的門檻，普及數位化程度並強化數位轉型準備度。

## 適用場景

- 尚未導入雲端系統、希望低成本嘗試數位工具的中小型製造業
- 已辦理工廠登記、需要快速補強 ERP / POS / 數位行銷的工廠
- 作為後續更大型 AI / 智慧化補助（如製造業 AI 應用、智慧機械）的入門前哨
